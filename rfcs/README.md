## How to submit an RFC / Cómo enviar un RFC

1. Read [RFC-001](RFC-001-rfc-process-and-deprecation-policy.md) for the full process.
2. Copy [RFC-TEMPLATE.md](RFC-TEMPLATE.md) (TBD — added with RFC-001 merge).
3. Create `RFC-NNN-{slug}.md` with the next sequential number.
4. Open a pull request titled `RFC-NNN: {title}`.
5. A GitHub Discussion thread will be created automatically for community comments.

## RFC states / Estados de los RFCs

- **Draft** — Author iterating, not yet ready for public comment.
- **Open for Comment** — Public comment window active.
- **Final Comment Period** — Final 1-week window before decision.
- **Accepted** — Approved; implementation tracking begins.
- **Rejected** — Declined with rationale captured.
- **Returned** — Sent back to author for revision.
- **Withdrawn** — Author retracted.
- **Implemented** — Merged into protocol and reference implementation.
- **Superseded** — Replaced by a later RFC.

See [RFC-001 §3.1](RFC-001-rfc-process-and-deprecation-policy.md) for full lifecycle.
